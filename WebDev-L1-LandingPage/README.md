# FITZONE – Fitness & Wellness Club

## Project Overview
FITZONE is a modern and responsive fitness landing page designed for a fitness and wellness club. It promotes fitness services through an attractive user interface and clean design.

## Features
- Sticky Navigation Bar
- Attractive Hero Section
- Fitness Services Section
- About Us Section
- Contact Section
- Social Media Links
- Responsive Design for Mobile and Desktop
- Modern Dark Theme with Neon Green Color Palette

## Technologies Used
- HTML5
- CSS3
- Google Fonts
- Flexbox and CSS Grid

## Project Structure
```text
WebDev-L1-LandingPage/
│
├── index.html
├── style.css
└── README.md
```

## How to Run the Project
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. The FITZONE landing page will open in your browser.
